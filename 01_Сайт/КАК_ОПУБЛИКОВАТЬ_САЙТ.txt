КАДР — КАК ОПУБЛИКОВАТЬ САЙТ
Пошаговая памятка для Исаева Аяна

Сначала распакуйте «Аян_КАДР_САЙТ.zip». Откройте папку KADR_AYAN_SITE.
В ней на одном уровне должны находиться:
  index.html
  style.css
  script.js
  images/ (папка с иллюстрациями)
  README.md

ВАЖНО: на хостинг нужно загружать СОДЕРЖИМОЕ этой папки так, чтобы index.html находился в корне сайта. Не загружайте внутрь ещё одну лишнюю папку KADR_AYAN_SITE.

ВАРИАНТ 1. GITHUB PAGES (РЕКОМЕНДУЕТСЯ ДЛЯ ЛАБОРАТОРНОЙ)

1. Войдите в свой аккаунт на https://github.com. Если аккаунта нет, зарегистрируйтесь.
2. Откройте https://github.com/new.
3. Repository name: kadr-monitor-tv-ayan (или другой свободный вариант). Visibility: Public. Создайте репозиторий.
4. В репозитории нажмите Add file → Upload files.
5. Перетащите из KADR_AYAN_SITE следующие элементы: index.html, style.css, script.js, папку images и README.md. Можно добавить этот гайд, но это необязательно.
6. Внизу нажмите Commit changes. Убедитесь, что index.html расположен в корне репозитория, а images лежит рядом с ним.
7. Откройте Settings → Pages. В разделе Build and deployment выберите Source: Deploy from a branch.
8. Выберите Branch: main, Folder: /(root), затем Save.
9. Подождите публикации (несколько минут). Снова откройте Settings → Pages: появится ссылка на сайт, примерно https://ВАШ-ЛОГИН.github.io/kadr-monitor-tv-ayan/.
10. Откройте полученный адрес в новой вкладке и на телефоне. Проверьте изображения, поиск, фильтры и корзину. Если ссылка пока не работает, проверьте Actions и Pages, подождите завершения процесса.

ВАРИАНТ 2. NETLIFY DROP (БЫСТРАЯ ПУБЛИКАЦИЯ)

1. Откройте https://app.netlify.com/drop и войдите в Netlify, если сервис попросит.
2. Перетащите ИМЕННО папку KADR_AYAN_SITE, в которой находится index.html, на область загрузки.
3. Дождитесь появления ссылки вида https://имя-сайта.netlify.app/.
4. Перейдите по ссылке, проверьте каталог и мобильный вид. Сохраните адрес для отчёта.
5. Примечание: методичка также требует репозиторий GitHub. Netlify не заменяет этот пункт: выполните шаги 1–6 первого варианта, если учитель требует обе ссылки.

КАК СДЕЛАТЬ РЕАЛЬНЫЕ СКРИНШОТЫ ДЛЯ ОТЧЁТА

1. Откройте ОПУБЛИКОВАННЫЙ сайт в Chrome или Edge на компьютере.
2. Нажмите Win + Shift + S, выделите страницу и сохраните скриншот в папку KADR_AYAN_REPORT/screenshots/ как 01_главная_ПК.png.
3. Прокрутите к каталогу и сделайте 02_каталог_ПК.png.
4. Нажмите F12 → Ctrl + Shift + M (режим устройства), выберите ширину 390 px, убедитесь, что страница адаптировалась. Сделайте 03_мобильная_версия.png.
5. Откройте фильтр/корзину и сделайте 04_фильтры_и_корзина.png.
6. Приложенные файлы preview_*.png — предварительный статический просмотр, а НЕ скриншоты работающего браузера. Не называйте их доказательством публикации.
